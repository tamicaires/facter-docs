# Mockups

Cada mockup é uma página HTML guardada exatamente como foi aprovada ou discutida. Abra pelo link: ela roda no navegador, com os estados que funcionam (filtros, "Quero isso", diálogos). A implementação segue o mockup aprovado; mudança de tela depois de aprovada atualiza o mockup antes do código.

Arquivos em `static/mockups/truck/<nome>/`: `index.html`, `desktop.png` e `phone.png`.
