# Mockups

Cada mockup é uma página HTML guardada exatamente como foi aprovada ou discutida. "Ver o mockup" abre em tela cheia dentro deste site, igual ao original e com os estados que funcionam (filtros, "Quero isso", diálogos). A implementação segue o mockup aprovado; mudança de tela depois de aprovada atualiza o mockup antes do código.

Arquivos em `static/mockups/truck/<nome>/`: `index.html`, `desktop.png` e `phone.png`.
