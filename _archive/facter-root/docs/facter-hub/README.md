## O que é o Facter Hub?

O Facter Hub é a plataforma central do ecossistema Facter, responsável por:

- **Identity** - SSO, autenticação, gestão de usuários
- **Companies** - Empresas e membros
- **Products & Plans** - Catálogo de produtos e planos
- **Subscriptions** - Gestão de assinaturas
- **Entitlements** - Permissões comerciais
- **Billing** - Stripe, invoices, pagamentos
- **Feature Flags** - Rollout, experimentos
- **Analytics** - Métricas e dashboards
- **Audit** - Logs de auditoria e compliance
