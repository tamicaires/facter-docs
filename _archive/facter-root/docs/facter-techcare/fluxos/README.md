## Fluxo Principal: Ordem de Serviço

```
                    ┌─────────────────┐
                    │    CLIENTE      │
                    │  Traz Equip.    │
                    └────────┬────────┘
                             │
                             ▼
┌─────────────────────────────────────────────────────────────────────────┐
│                        RECEBIMENTO (Atendente)                          │
├─────────────────────────────────────────────────────────────────────────┤
│ • Identificar/cadastrar cliente                                         │
│ • Registrar equipamento (fotos, condição)                              │
│ • Anotar defeito relatado                                              │
│ • Gerar número da OS                                                   │
│ • Entregar comprovante ao cliente                                      │
└────────┬────────────────────────────────────────────────────────────────┘
         │
         ▼
┌─────────────────────────────────────────────────────────────────────────┐
│                         TRIAGEM (Atendente)                             │
├─────────────────────────────────────────────────────────────────────────┤
│ • Avaliar urgência                                                      │
│ • Definir prioridade                                                    │
│ • Encaminhar para fila de diagnóstico                                  │
└────────┬────────────────────────────────────────────────────────────────┘
         │
         ▼
┌─────────────────────────────────────────────────────────────────────────┐
│                       DIAGNÓSTICO (Técnico)                             │
├─────────────────────────────────────────────────────────────────────────┤
│ • Analisar equipamento                                                  │
│ • Identificar problema real                                             │
│ • Definir procedimentos necessários                                    │
│ • Verificar peças disponíveis                                          │
│ • Gerar orçamento                                                       │
└────────┬────────────────────────────────────────────────────────────────┘
         │
         ▼
┌─────────────────────────────────────────────────────────────────────────┐
│                  AGUARDANDO APROVAÇÃO (Sistema)                         │
├─────────────────────────────────────────────────────────────────────────┤
│ • Enviar orçamento ao cliente (Email/WhatsApp)                         │
│ • Cliente acessa link para visualizar                                   │
│ • Aguardar decisão do cliente                                          │
└────────┬────────────────────┬───────────────────────────────────────────┘
         │                    │
    ┌────┘                    └────┐
    │                              │
    ▼                              ▼
┌──────────────┐           ┌──────────────┐
│   APROVADO   │           │   REJEITADO  │
│  (Cliente)   │           │  (Cliente)   │
└──────┬───────┘           └──────┬───────┘
       │                          │
       ▼                          ▼
┌──────────────────┐      ┌──────────────────┐
│ Verificar Peças  │      │    DEVOLUÇÃO     │
│   em Estoque     │      │   sem reparo     │
└──────┬───────────┘      └──────────────────┘
       │
   ┌───┴───────────────────┐
   │                       │
   ▼                       ▼
┌──────────────┐    ┌──────────────────┐
│ Peças OK     │    │ AGUARDANDO PEÇAS │
│              │    │ (Solicitar)      │
└──────┬───────┘    └────────┬─────────┘
       │                     │
       │                     │ (Peças chegam)
       │                     │
       └─────────┬───────────┘
                 │
                 ▼
┌─────────────────────────────────────────────────────────────────────────┐
│                        EM EXECUÇÃO (Técnico)                            │
├─────────────────────────────────────────────────────────────────────────┤
│ • Realizar reparo                                                       │
│ • Registrar peças utilizadas                                           │
│ • Documentar procedimentos (fotos)                                     │
│ • Testar equipamento                                                    │
└────────┬────────────────────────────────────────────────────────────────┘
         │
         ▼
┌─────────────────────────────────────────────────────────────────────────┐
│                        FINALIZADO (Técnico)                             │
├─────────────────────────────────────────────────────────────────────────┤
│ • Emitir laudo técnico                                                  │
│ • Fotos do equipamento reparado                                        │
│ • Notificar cliente                                                     │
└────────┬────────────────────────────────────────────────────────────────┘
         │
         ▼
┌─────────────────────────────────────────────────────────────────────────┐
│                       PAGAMENTO (Atendente)                             │
├─────────────────────────────────────────────────────────────────────────┤
│ • Registrar forma de pagamento                                          │
│ • Emitir recibo/NF                                                      │
│ • Confirmar pagamento                                                   │
└────────┬────────────────────────────────────────────────────────────────┘
         │
         ▼
┌─────────────────────────────────────────────────────────────────────────┐
│                        ENTREGA (Atendente)                              │
├─────────────────────────────────────────────────────────────────────────┤
│ • Conferir equipamento com cliente                                      │
│ • Verificar acessórios                                                  │
│ • Entregar termo de garantia                                           │
│ • Coletar assinatura                                                   │
└────────┬────────────────────────────────────────────────────────────────┘
         │
         ▼
┌─────────────────────────────────────────────────────────────────────────┐
│                         ARQUIVADO                                       │
├─────────────────────────────────────────────────────────────────────────┤
│ • OS completa no histórico                                              │
│ • Disponível para consulta                                              │
│ • Garantia ativa                                                        │
└─────────────────────────────────────────────────────────────────────────┘
```
